# 🌊 Atlantis Firmware

> Open-source capacitive touch firmware for ESPHome and Home Assistant.

Atlantis is an ESPHome-based firmware for building elegant capacitive touch switches with smooth LED animations and seamless Home Assistant integration.

The goal of Atlantis is to create a touch experience that feels responsive, natural and visually pleasing instead of behaving like a simple on/off button.

---

## ✨ Features

- Capacitive touch input with adaptive baseline
- Noise-resistant touch detection
- Smooth pulse animation
- Center-out LED rendering
- Home Assistant integration
- ESPHome based
- Fully open source

- ESPHome

Future hardware revisions may support additional LED layouts and ESP32 variants.

---

## Philosophy

Atlantis is designed around one simple idea:

> A smart switch should feel alive.

Instead of reacting instantly like a traditional button, Atlantis uses smoothing, adaptive touch processing and carefully designed animations to create a more premium user experience.
